# Potey House website

Open `index.html` to preview the site.

## Before publishing
1. Open `script.js`.
2. Replace `97798XXXXXXXX` with your mom's WhatsApp number (country code + number, digits only).
3. Replace the sample product names/prices in `script.js`.
4. Replace the emoji product visuals with your real product photos later.

## Publish free with GitHub Pages
Create a GitHub repository, upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
Then open the repository's Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
GitHub will provide a public URL.
